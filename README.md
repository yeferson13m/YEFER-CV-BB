# CV web — Yeferson Mamani Quispe

Sitio de currículum/portafolio personal construido con HTML, CSS y JavaScript.

## Archivos
- `index.html`: contenido del CV.
- `css/style.css`: estilos, diseño adaptable y estilos de impresión.
- `js/script.js`: navegación suave y botón para imprimir/guardar como PDF.
- `assets/profile.jpg`: fotografía de perfil.

## Ver localmente
Abre `index.html` en tu navegador. No necesita instalación ni compilación.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub (por ejemplo, `yeferson-mamani-cv`).
2. Descomprime este ZIP y sube el contenido de la carpeta, conservando la estructura de archivos.
3. En GitHub, entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera la publicación; GitHub mostrará la dirección pública del sitio en esa misma sección.

## Guardar como PDF
Abre la página en Chrome y pulsa **Guardar CV**. En el diálogo de impresión elige **Guardar como PDF**. Para mejores resultados activa los gráficos de fondo.

## Personalización
Edita el texto directamente en `index.html` y los colores en `css/style.css`. Mantén `assets/profile.jpg` en su ubicación para que la fotografía se visualice correctamente.
